Golden honey pours over a warm stack of fluffy pancakes and a melting pat of butter. A dependency-free TypeScript ray marcher renders the scene with signed distance fields, soft light, glossy reflections and its own PNG encoder.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts  # writes out/entry.png
```
